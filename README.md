# 🏎️ Scuderia Ferrari

> 🥉 **Meu 3º projeto.** Aqui eu evoluí do HTML e CSS puros para um site responsivo, com JavaScript e bibliotecas de estilo.

Site em homenagem à **Scuderia Ferrari** na Fórmula 1, com a história da equipe, os pilotos, um quiz e um formulário.

## 🎯 Sobre o projeto

Um site de 5 páginas sobre a Ferrari, com menu que se adapta ao tamanho da tela (celular e computador) e interações feitas com JavaScript.

## 📄 Páginas

| Página | O que tem |
|---|---|
| **Home** (`index.html`) | Apresentação da equipe e a seção "Nossos Títulos": 16 títulos de construtores, 15 de pilotos e mais de 240 vitórias na Fórmula 1 |
| **História** (`historia.html`) | A trajetória em cinco fases: O Início na Fórmula 1, Primeiros Títulos, Era de Ouro com Schumacher, Desafios e Reconstrução e A Ferrari Hoje |
| **Nossos Pilotos** (`nossospilotos.html`) | Pilotos atuais e reservas, e um texto sobre a trajetória até chegar à equipe |
| **Quiz** (`quiz.html`) | 5 perguntas com correção em JavaScript: mostra ✅ ou ❌ em cada resposta e o total de acertos |
| **Fale Conosco** (`faleconosco.html`) | Formulário "Participe da próxima corrida da Ferrari" (nome, sobrenome, estado e outros campos) |

## ⚙️ Funcionalidades

- **Menu hambúrguer** que abre e fecha no celular (JavaScript)
- **Layout responsivo**, com regras de CSS diferentes para telas menores e maiores que 768px
- **Quiz interativo** com resultado na hora
- **Efeito de sublinhado** nos links do menu ao passar o mouse

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Hover.css](https://ianlunn.github.io/Hover/)
- [Hamburgers](https://jonsuh.com/hamburgers/)

As bibliotecas são carregadas por CDN, então não precisa instalar nada.

## 📌 O que eu pratiquei

- Responsividade com `@media`
- Organização do projeto em pastas (`html`, `css`, `imagens`)
- Manipulação do DOM: `querySelector`, `addEventListener` e `classList.toggle`
- Correção de quiz com `for` e `querySelector`
- Uso de bibliotecas externas por CDN

## 🚀 Como rodar o projeto

1. Baixe ou clone o repositório
2. Abra o arquivo `html/index.html` no navegador

## ⚠️ Observação

O formulário do "Fale Conosco" é só visual: os dados não são enviados para lugar nenhum.
